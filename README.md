# paper_writing

A Claude Code skill for writing robotics / robot-learning papers in the style of a *Science Robotics* associate editor.

Install: copy this folder to `~/.claude/skills/paper_writing`. The sub-skills `project/`, `website/`, and
`video/` can be linked as `~/.claude/skills/paper-project`, `project-website`, and `promo-video`.
